Get Started with MongoVault

Paste a MongoDB connection URI. When the backend is connected, MongoVault will read the collections you can access, write them as JSON, and package them into one ZIP. This page does not open a database.

  1. Connect. Enter the connection URI for the database you want to export.
  2. Package. The server will write each collection as JSON.
  3. Download. Save one ZIP locally. That step is not available yet.

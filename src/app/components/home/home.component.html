Workflow

Three steps. No extra tooling.

Packaging is a server-side step in the planned design. This website does not open a database connection.

  1. Connect

    Paste your MongoDB connection URI.

  2. Package

    The server will securely export collections as JSON and package them into a ZIP.

  3. Download

    Save your database backup locally.

Trust

Specific controls, not slogans.

These controls are planned for the backend. They are not active on this static page, and this site does not claim a finished security model.

  • Planned

    Secure handling of connection credentials

    The URI is intended to be used only for the export request, with handling defined before any connection is made.

  • Planned

    No permanent backup storage by default

    The archive is meant to be delivered as a download rather than kept on a server.

  • Planned

    Connection and export limits

    Timeouts and size limits are part of the intended design so a request cannot run without bound.

  • Recommended

    Read-only MongoDB access

    When export is available, use a database user that can read the data you need and nothing more.
